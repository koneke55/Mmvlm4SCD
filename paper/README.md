# Paper

`paper/paper.pdf` is the quantitative study generated by
`paper/build_paper.py`. It is built from the JSON artefacts produced by

```bash
python src/scripts/run_full_experiment.py --config configs/default.yaml --seeds 3 --ablate
python src/scripts/run_baselines.py
python paper/build_paper.py --out paper/paper.pdf
```

The PDF is therefore always traceable to a concrete experiment run. To
regenerate after a change, repeat the three commands above.
